# Streamlit 売上データ管理サンプル

CSV の売上データを絞り込み、顧客分類を編集し、売上集計をグラフで確認するシンプルな Streamlit アプリです。

## 機能

- 左サイドバーから、対象年・担当者・顧客名を候補検索できる複数選択でフィルタ。いずれも初期状態では絞り込みなし
- 左サイドバーで複数のソート列、優先順位、列ごとの昇順・降順を指定。初期順は「対象日付」「顧客分類」「顧客名」
- 表では薄い黄色の背景で表示される「顧客分類」列のみ編集可能
- 顧客分類はマスタに登録された候補から選択（自由入力不可）
- 別画面の「顧客分類マスタ」で選択候補を追加・削除
- 編集した顧客分類を「保存」ボタンで CSV に保存
- 「グラフを更新」ボタンで編集内容をグラフへ反映
- 年月別売上金額を棒グラフで表示
- 顧客分類別売上金額を円グラフで表示
- 100 件のサンプルデータを同梱

> テーブルを編集しただけでは CSV やグラフへ確定されません。「保存」で CSV へ書き込み、「グラフを更新」でグラフへ反映してください。

## 動かし方

Python 3.10 以上を推奨します。

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

コマンド実行後、通常はブラウザで `http://localhost:8501` が開きます。

## ファイル構成

```text
.
├── app.py                    # Streamlit アプリ
├── pages/
│   └── 1_顧客分類マスタ.py   # 顧客分類のメンテナンス画面
├── sample_sales.csv          # サンプル売上データ（100件）
├── customer_categories.csv   # 顧客分類マスタ
├── requirements.txt          # Python 依存パッケージ
└── README.md
```

CSV の列は `対象日付`, `種別`, `種別名`, `部署`, `部署名`, `担当者`, `顧客名`, `顧客分類`, `売上金額` です。既存列を残したまま、数値型の `種別` と `部署`、それぞれに対応する文字列型の名称列を追加しています。サンプルでは全行の種別を `5`、種別名を `売上`、部署を `44`、部署名を `全社` としています。`対象日付` は `YYYY-MM-DD` 形式、`売上金額` は整数で記録しています。

## 顧客分類マスタ

アプリ起動後、Streamlit のページナビゲーションから「顧客分類マスタ」を開くと、選択候補の追加・削除ができます。空欄や重複した分類は保存できません。また、売上データで使用中の分類を削除する場合は、先にメイン画面で該当する売上データの顧客分類を変更して保存してください。
